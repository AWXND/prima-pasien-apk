Cara Install

01
Tekan tombol download di atas atau scan QR code menggunakan kamera HP.
02
Buka file yang sudah terunduh dari notifikasi atau folder Download. Jika muncul peringatan "sumber tidak dikenal", tekan "Setelan" lalu izinkan install dari sumber ini — ini normal karena aplikasi belum tersedia di Play Store.
03
Tekan "Pasang" (Install) dan tunggu hingga selesai.
04
Buka aplikasi Prima Pasien dan mulai ambil nomor antrean Anda.
Aplikasi ini adalah aplikasi resmi RS Prima Ternate. Sementara dalam proses pendaftaran ke Google Play Store, unduhan tersedia langsung melalui halaman ini. Butuh bantuan? Tanyakan ke petugas pendaftaran.
